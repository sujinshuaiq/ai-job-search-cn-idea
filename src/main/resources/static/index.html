DeepSeek 配置

在 IDEA 的 Run Configuration 中添加环境变量，然后重启应用：

DEEPSEEK_API_KEY=sk-你的密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash

密钥不会显示在页面、写入数据库或打印到日志。未配置时自动使用本地规则模式。
