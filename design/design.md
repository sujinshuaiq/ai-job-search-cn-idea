# 浏览器协同页增量设计

## 体验目标

在现有“职航”工作台内提供一个清晰的“浏览器协同 + MCP”标签页，让首次使用者按“输入岗位并打开 → 人工搜索后确认采集”两步完成操作。保留离线 HTML、原在线单页和手动录入，不改变现有视觉系统。

## 信息架构

1. 顶部说明条：蓝色紫渐变浅色卡片，说明“AI 不代替你登录或搜索”。
2. 第一步卡片：自然语言输入与关键词/城市/条数表单合并，支持“解析并打开 BOSS”和“按上方条件直接打开”；有头模式和基础页选项收进高级设置。
3. 第二步卡片：当前活动标签状态、URL、人工操作提示和“确认当前页并采集”主按钮；采集按钮本身代表明确确认，不设置重复复选框。
4. 结果区：显示真实解析、新增、重复数和前 5 个职位预览，不设计假进度。
5. MCP 折叠说明：五个工具名、STDIO 启动命令和配置文件位置。

## 视觉与交互

- 沿用深紫 `#7057e8`、墨蓝 `#182033`、浅灰 `#f5f6fa`、绿色成功色和既有 18px 面板圆角。
- 步骤编号使用 32px 圆形浅紫底，主操作保持紫色，关闭操作使用白底红字。
- 表单在桌面两列，移动端单列；状态文本允许换行，长 URL 使用 `word-break: break-all`。
- 所有按钮调用真实 API；请求中禁用当前按钮并显示具体阶段，全局顶部进度条继续复用。
- 重复打开保留当前 BOSS 页；状态同步只读取活动标签，不刷新网页。搜索新标签由用户激活后再采集。
- 不加入动画干扰人工扫码；不使用外部字体、图标 CDN 或虚假在线状态。

## 验证重点

- 页面四个标签可切换，既有功能无回归；浏览器协同恰好两个步骤、无独立确认框。
- 无 DeepSeek Key 时自然语言仍能解析并标记 `LOCAL_RULES`。
- 后端未收到明确确认时仍拒绝采集；搜索打开新标签后跟随可见 BOSS 标签。
- 重复打开不调用导航，浏览器未启动、站外 URL、验证页和解析失败均显示真实错误。
- 移动端 390px 无横向溢出，桌面 1440px 保持现有工作台布局。
