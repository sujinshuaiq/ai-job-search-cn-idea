# 职位导入与可选浏览器协同页设计

## 体验目标

默认提供步骤最少的离线 HTML 导入和手动录入，不让首次使用者先经历浏览器启动、登录和确认等步骤。可选“浏览器协同 + MCP”保留原两步人工流程，但必须明确标注默认关闭和账号风险。

## 信息架构

1. 顶部说明条：默认离线安全模式，不自动打开、刷新或请求 BOSS；不把该默认值宣传为防封号技术。
2. 默认标签：离线 HTML 导入，支持文件选择、粘贴、演示 HTML 和真实解析/新增/重复结果。
3. 手动录入：支持其他国内招聘平台或线下职位。
4. 可选浏览器协同：标注“默认关闭”；显式开启后才使用原“打开基础页 → 人工搜索 → 确认当前页”两步卡片。
5. 可选在线单页：标注“默认关闭”；合法请求默认由服务端返回 `BOSS_ONLINE_DISABLED`，不执行 robots 或网络请求。
6. MCP 折叠说明：保留五个工具和 STDIO 命令，同时说明默认禁用边界和独立 JVM 环境变量。

## 视觉与交互

- 沿用深紫 `#7057e8`、墨蓝 `#182033`、浅灰 `#f5f6fa` 和既有面板圆角。
- 页面初始化调用 `showCrawlerTab("offline")`，HTML 默认状态也让离线面板可见、浏览器面板隐藏。
- 表单桌面两列、移动端单列；长 URL 和错误说明允许换行。
- 所有按钮调用真实 API；默认禁用错误必须直接展示，不用假成功或虚假在线状态。
- 可选浏览器功能开启后，重复打开仍保留当前 BOSS 页，状态同步不刷新网页，当前页读取必须人工确认。
- 不加入 stealth、代理池、验证码绕过、自动填词、自动翻页或外部 CDN。

## 验证重点

- 首屏和从其他导航进入采集页都默认离线；四个标签仍可切换。
- 默认 open/collect 返回 `BOSS_BROWSER_DISABLED`，search 返回 `BOSS_ONLINE_DISABLED`，且拒绝发生在 Playwright、robots 和网络请求之前。
- 离线演示 HTML 可导入，重复导入去重；手动录入不受影响。
- 显式开启后的原有幂等打开、活动标签和确认边界测试仍保留。
- 移动端 390px 无横向溢出，桌面保持现有工作台布局。
